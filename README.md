# golf-demo-app

Vibe Coding ワークショップ用の **ゴルフ上達アプリ** のベースです。
ローカルだけで動く最小限の Web アプリで、ここから Kiro CLI との対話で機能を拡張していくのがワークショップのゴールです。

## こんなアプリ

- ブラウザで PC のカメラ映像をリアルタイムに姿勢推定
- 骨格を映像にオーバーレイ表示し、姿勢スコアを常時表示
- 「録画開始」ボタンでスイングのクリップを録画して履歴に保存
- すべて **1 画面で完結**(画面遷移なし)

すべて **ローカル完結** です。映像やデータが外部サーバーに送られることはありません。

> **履歴クリップの再生機能は意図的に実装していません**。ワークショップで Kiro に「履歴を再生したい」と依頼するところからスタートしてみてください。

## 必要なもの

- Node.js 20 以上
- **PC のカメラ**(内蔵 Webcam か USB カメラ)
- モダンなブラウザ(**Chrome / Edge 最新版を推奨**、Safari も可)
- 1024px 以上の画面幅(デスクトップ専用、スマホ非対応)

## セットアップ

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:5173` を開いてください。
**初回起動時にカメラへのアクセスを求められるので「許可」してください。**

## 使い方

1. アプリを開くとカメラが自動で起動し、リアルタイムに骨格が表示される
2. サイドバーに姿勢スコアが常時表示される
3. ゴルフのスイングをして「● 録画開始」ボタン(またはキーボードの `R`)を押すと録画開始
4. もう一度押す(または `R`)と録画停止 → 履歴に自動保存
5. 履歴は日時・スコア・録画長で一覧表示される(再生機能はワークショップ拡張で追加してください)

### キーボードショートカット

- `R` — 録画開始 / 停止
- `Esc` — 録画中なら停止

## トラブルシューティング

**カメラが起動しない / 「アクセス拒否」と表示される**
→ ブラウザのアドレスバーのカメラアイコンから許可してください。一度拒否してしまった場合はサイト設定からリセットが必要です。
→ 別のアプリ(Zoom 等)がカメラを掴んでいないか確認してください。

**骨格が表示されない**
→ MediaPipe のモデル読み込みに失敗している可能性。ネット接続を確認するか、ブラウザのコンソールを見てください(初回はモデルファイルを CDN から取得します)。

**録画ができない / 保存に失敗する**
→ Safari は WebM 非対応の場合があります。Chrome / Edge を試してください。
→ ブラウザのストレージ容量を確認してください。

**保存したクリップが消えた**
→ ブラウザのストレージをクリアすると IndexedDB のデータも消えます。シークレットウィンドウでは保持されません。

**LAN 越しに別端末から触りたい**
→ `getUserMedia` は `localhost` 以外では HTTPS 必須です。`vite --host` だけでは動きません。`@vitejs/plugin-basic-ssl` 等で自己署名証明書を有効にしてください。
